# Afshan Ansari — Portfolio

A responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content
- `style.css` — visual design and responsive layout
- `script.js` — scroll reveal and mobile navigation

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `afshan-portfolio`.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live Pages URL.

## Before publishing
Replace the placeholder GitHub and LinkedIn URLs in `index.html` with your actual profiles.

Also review the PwC/Xcel wording so it exactly matches what you are permitted to disclose publicly.
Do not publish confidential client information, internal screenshots, proprietary workflow details, credentials, or private project data.
